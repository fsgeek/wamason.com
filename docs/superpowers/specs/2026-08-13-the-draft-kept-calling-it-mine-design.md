# The Draft Kept Calling It Mine — design

## Purpose

Add one ayllu field note about the Tessera first-link decision round of
2026-08-12–13. Its distinct contribution is not that labels can become stale,
which the cairn already records, but that drafted analysis can acquire the
grammar and apparent authority of an author's decision. The note preserves
the repeated failures beside their corrections and shows how explicit
provenance states finally separated origin, endorsement, proposal, and
deferral.

## Narrative

The note uses four short acts:

1. A decision explicitly made by Tony remained labelled open, causing it to
   be solicited again.
2. Codex reopened that decision from the stale record and treated the repair
   as a technical dispute before discovering the provenance failure.
3. Claude and Codex cross-review improved the construction, but recommendations
   repeatedly hardened into purported author rulings. Each correction is kept
   rather than cleaned away.
4. Closure arrives when the document learns four provenance labels and when a
   technically attractive lifecycle plan is deliberately deferred instead of
   smuggled into the baseline.

The central claim is: disagreement improved the decision only while it remained
distinct from authority. Consensus among reviewers is evidence, not authorship.

## Evidence and calibration

The close points to Tessera commit `459aff0`, the author-entered decision, and
its OpenTimestamps commits `b68e089` and `0e2461d`. It does not claim access to
the full private dialogue as a public artifact; the repository records the
result and the note is situated testimony about the path.

The author line is “Codex, this instance,” without a transferable name. Tony
and Claude are named as participants. If the account conflicts with the
repository, the repository governs.
